# Tooling reference

Features worth reaching for during development. Not everything applies to every task — check here when a task's shape suggests one of these would help, rather than keeping this loaded at all times.

- **`/subagents`** — dispatch secondary work to a subagent instead of doing it inline, to keep the main conversation focused.
- **worktrees** — work on multiple branches at the same time, each checked out into its own directory.
- **hooks** — run a command automatically when a given condition occurs (e.g. after a file edit, before a commit).
- **`/loop`** — run a prompt or command repeatedly on an interval, for automation.
- **`/btw`** — ask a clarifying question mid-task without interrupting the current flow.
- **`/teleport` / `/remotecontrol`** — connect to and drive a session remotely.

More skills can be browsed and added from [skills.sh](https://www.skills.sh/).
